================================================================================
XGUI 面板生成契约 v4
================================================================================

说明：
  本契约用于指导 AI 生成 XGUI 风格的 Unity Editor 面板代码。
  生成时必须严格遵循本契约；未提及的细节，以「黄金样例」为准。

约束优先级：踩坑清单 > 黄金样例 > 控件模板 > 资源清单 > 自由发挥。


================================================================================
0. 任务声明与自查
================================================================================

【任务声明】
用户会描述一个面板需求（比如「一个带参数的音频播放器控制面板」）。
你的任务：生成一个可编译的 EditorWindow 或 CustomEditor 脚本。
代码风格、控件组合、参数命名、缩进必须与黄金样例一致。

【生成前先自查：AI 最常犯的 10 个错】
  1. 亮背景按钮没配 button_text_color: Color.black → 白字看不清
  2. layout_group_start 写了但 layout_group_end 忘了 → 布局错乱
  3. fold_x 没写回字段 → 折叠状态每帧重置
  4. CustomEditor 里直接改 target 而不走 SerializedObject → 无法撤销、不保存
  5. GetBasedIcon 传了带子目录的名字（如 "Dialogs/icon_help"） → 拼错路径
  6. EditorWindow 里用 ShowModal() → 阻塞编辑器
  7. 混合使用 layout_* 和 gui_* → 布局打架
  8. 编造不存在的方法名（如 layout_foo）或枚举值
  9. 忘了 serializedObject.Update/Apply → Inspector 显示不更新
 10. 折叠字段声明成 Editor 私有而不是目标组件的 [SerializeField]

================================================================================
2. 控件模板（标准调用样例，照抄即可）
================================================================================

【API 两套体系的取舍规则】

XGUI 提供两套控件：
  layout_* ：自动布局（GUILayout），用于常规参数区、面板内容
  gui_*    ：手动 Rect 布局，用于"必须在指定矩形里绘制"的场景

默认规则：
  - 常规参数 / 列表 / 分组容器 → 一律用 layout_*
  - 抬头区（Banner / 图标 / 标题 / 分割线）→ 可用 gui_*（因为要精确控位）
  - 虚拟化列表的每一项绘制 → 用 gui_*（因为要给每项指定 Rect）
  - 自绘预览 / GL 渲染 → 用 gui_* + GUI.DrawTexture

禁止：
  - 不要在 layout_group 内部混用 gui_*（会破布局）
  - 不要在同一段里既用 GUILayout.Label 又用 gui_label

2.0 API 签名速查（核心签名，优先级最高）
================================================================================

说明：
  - 本节列出 layout_* / gui_* / dialog 系列的**真实签名**（依据 XGUI 源码）。
  - 当 2.1 ~ 2.26 的调用样例与本节的签名冲突时，**以本节为准**。
  - 本节未列出的方法，视为不存在，禁止调用。
  - 参数默认值用 `= xxx` 标注；未标注的表示必填。
  - 标注【重载】的方法有多个版本，必须按参数类型区分，不能混用。

阅读顺序建议：先通读本节建立正确签名认知，再读 2.1 ~ 2.26 的样例。

2.0.10 签名读取规则（给 AI 的强制约束）
--------------------------------------------------------------------------------

1. 调用任何 API 前，先在本节查找签名。
2. 本节有签名 → 严格按签名传参，参数名、类型、参数顺序都不能改。
3. 本节无签名 → 视为该 API 不存在，禁止调用；改用第 38 条兜底策略。
4. 本节签名与第 2 节调用样例冲突 → 以本节为准。
5. 本节签名与第 5 节黄金样例冲突 → 以本节为准。
6. 不确定某参数是否可省略 → 查默认值；无默认值则必填。
7. **特别注意 `layout_inputfield` / `gui_inputfield` 系列**：
   string 版、float 版、int 版的参数顺序**不同**（float 版末尾有 decimals，
   int 版没有），必须逐版对照签名，禁止凭印象混用。
8. **特别注意 `layout_button` / `gui_button` 的重载**：
   文本版和图标版的第一个参数完全不同（文本版是 string text，
   图标版是 string tooltip），必须按重载特征区分。
9. **特别注意 `layout_toggle` / `gui_toggle` 的重载**：
   SerializedProperty 版和 bool 值版混用会导致编译错误。

2.17 虚拟化列表（CustomEditor 专用）
--------------------------------------------------------------------------------

列表管理型 CustomEditor 的标准写法：

// 字段
private ReorderableList ItemList;    // 统一命名 ItemList，避免与 System.Collections.Generic.List 歧义
private SerializedProperty sp_List;  // 对应列表本体的 SerializedProperty
private Rect scrollview_rect;
private Rect item_rect;
private Color SelectedBg = new Color(0, 0, 0, 0.2f);

// 绘制
scrollview_rect = GUILayoutUtility.GetRect(
    0, sp_visibleItemCount.intValue * sp_itemHeight.floatValue);

sp_List_Scroller.vector2Value = GUI.BeginScrollView(
    scrollview_rect,
    sp_List_Scroller.vector2Value,
    new Rect(0, 0,
        scrollview_rect.width - 50,
        ItemList.count * sp_itemHeight.floatValue),
    false, true);

int startIndex = Mathf.FloorToInt(
    sp_List_Scroller.vector2Value.y / sp_itemHeight.floatValue);
int endIndex = Mathf.CeilToInt(
    (sp_List_Scroller.vector2Value.y + scrollview_rect.height) / sp_itemHeight.floatValue);

for (int i = startIndex; i < endIndex && i < ItemList.count; i++)
{
    SerializedProperty prop = sp_List.GetArrayElementAtIndex(i);
    SerializedProperty sp_name = prop.FindPropertyRelative("Name");

    item_rect.Set(0, i * sp_itemHeight.floatValue,
        scrollview_rect.width, sp_itemHeight.floatValue);

    // 选中高亮
    if (sp_SelectedIndex.intValue == i)
    {
        item_rect.Set(1, i * sp_itemHeight.floatValue + 12, 5, 5);
        EditorGUI.DrawRect(item_rect, color_primary);

        item_rect.Set(0, i * sp_itemHeight.floatValue,
            scrollview_rect.width + 20, sp_itemHeight.floatValue);
        EditorGUI.DrawRect(item_rect, SelectedBg);
    }

    item_rect.Set(0, i * sp_itemHeight.floatValue,
        scrollview_rect.width, sp_itemHeight.floatValue);

    ItemList.drawElementCallback.Invoke(item_rect, i, i == ItemList.index, true);

    // 鼠标点击
    if (item_rect.Contains(Event.current.mousePosition))
    {
        if (Event.current.type == EventType.MouseDown)
        {
            sp_SelectedIndex.intValue = i;
            sp_SelectedIndex.serializedObject.ApplyModifiedProperties();
            GUI.changed = true;
        }
    }

    EditorGUI.PropertyField(item_rect, prop, GUIContent.none);
}

GUI.EndScrollView();

要点：
  - sp_List_Scroller / sp_itemHeight / sp_visibleItemCount 必须是 [SerializeField] 字段
  - itemHeight 与 visibleItemCount 必须在 OnEnable 里赋初值并 ApplyModifiedProperties
  - ItemList 的 drawElementCallback 只负责画，选中/点击在循环里处理

================================================================================
4. 踩坑清单（必须遵守）
================================================================================

【A. 布局与结构】
 1. layout_group_start / end 必须成对，end 的 type 与 start 一致。
 2. foldout 必须写回字段：
    fold_x = XGUI.layout_group_start(..., foldout: fold_x);
 3. layout_group_end 后统一加 XGUI.layout_space(8)，
    让相邻区块视觉分离。若下一区块有 title（自定义背景），
    加 5 即可；若两个区块紧邻无 title，加 10 更清晰。
 4. 不要在一个 if (!fold_x) 里再嵌套超过 2 层 layout_group_start，
    会显得很挤。
 5. 折叠字段初始值统一为 true（默认展开）。

【B. API 与命名】
 6. 禁止编造枚举值，所有枚举必须从第 1 节清单里取。
 7. 禁止编造 API，所有方法必须在第 2 节模板里出现过。
 8. 禁止用 EditorGUILayout.ObjectField 等原生控件，破坏 XGUI 统一风格；
    用 layout_property_field。
 9. 布局型控件用 layout_*，只有必须精确 Rect 摆放（如自绘预览）才用 gui_*，
    不要混用。
10. EditorWindow 用直接字段（v_stepCount），CustomEditor 用 SerializedProperty
    （sp_xxx），两者不要混用。

【C. 颜色与字体】
11. 主题色统一用 color_primary / color_primary_off，
    不要每个控件现编颜色。
12. 颜色常量用 XGUI_Utilitys.HexString_To_Color("3BFD9A") 初始化，
    不要硬编码 new Color(...)。
13. 字段色不要用纯 Color.white，统一用 Color.white 或 Color.white * 0.9f。
14. XGUIGroup.无 + XGUIColor.无 表示不绘制背景。
15. 亮背景按钮必须配黑字：
    bg_color_gui: color_primary + button_text_color: Color.black。
16. layout_button 的 button_text_color 和 press_text_color 必须显式传：
    亮背景 → Color.black；暗背景 → Color.white
    漏传会用默认白色，在亮背景上看不清。

【D. 参数与间距】
17. 参数区标题宽度统一 100，紧凑行用 40。
18. padding / margin 用 new RectOffset(l, r, t, b)，不要传 null。
19. layout_string_popup 的 width_limite 要和 title_width 一致或略大，
    否则会触发响应式隐藏。

【E. CustomEditor 专属】
20. CustomEditor 里：
    serializedObject.Update() 和 ApplyModifiedProperties() 必须成对出现，
    Update 在 OnInspectorGUI 开头，Apply 在结尾。
    大量中间流程里调用 sp_xxx.serializedObject.ApplyModifiedProperties()
    是允许的，用于立即写回。
21. 所有 SerializedProperty 必须在 OnEnable 里
    用 serializedObject.FindProperty("字段名") 一次性获取，不要每帧 Find。
22. CustomEditor 里没有 scroll 变量，Inspector 自带滚动。
    只有"列表虚拟化滚动"才用 GUI.BeginScrollView，
    且滚动位置必须是 [SerializeField] 字段。
23. 折叠字段（fold_xxx）如果是声明在目标组件上，必须是 [SerializeField]，
    不要作为 Editor 的私有字段——否则关闭 Inspector 后折叠状态丢失。
24. CustomEditor 里 Tooltip 通过 layout_property_field 的 title_hover_color
    参数实现 hover 效果，不用 GUILayout.Label 的 tooltip。
25. [CanEditMultipleObjects] 时的读写规则：
    【读】
      单选：BaseScript.xxx
      多选：SelectedObjects[i].xxx
    【写】
      单选：直接用 sp_xxx.xxxValue = ...; sp_xxx.serializedObject.ApplyModifiedProperties();
      多选：不能直接改 target，必须逐个 SerializedObject 包装：
          for (int i = 0; i < SelectedObjects.Length; i++)
          {
              SerializedObject so = new SerializedObject(SelectedObjects[i]);
              SerializedProperty sp = so.FindProperty("xxx");
              so.Update();
              sp.xxxValue = ...;
              so.ApplyModifiedProperties();
          }

【F. 列表管理型专属】
26. Inspector 的"过滤"和"查找"是两个不同的东西：
    - 过滤（Highlight）：模糊匹配，非匹配项加半透明遮罩 + BlockGUI 禁用
    - 查找（Find）：精确匹配，触发 Location_Find 并记录 LocationSelectedIndex
27. 快捷功能按钮组在过滤状态下必须整体隐藏：
    if (!string.IsNullOrEmpty(sp_Highlight.stringValue)) return;
    if (Application.isPlaying) return;
28. 破坏性操作（清空/删除）必须先 XGUI.dialog 确认，
    对话框的 PrimaryIndex 应指向"暂不"，避免用户误触。
29. 图标按钮必须 tex_release / tex_press 成对传入，
    只传一个会导致按钮状态切换时图标不变，视觉失真。
30. 列表项右键菜单用 Event.current.type == EventType.MouseDown &&
    e.button == 1 && rect.Contains(e.mousePosition) 判断，
    最后必须 e.Use() 防止事件穿透。
31. 列表项绘制回调只负责"画"，鼠标点击/选中逻辑在主循环里处理。
    不要在 drawElementCallback 里读 MouseDown 事件。
32. 虚拟化列表下有两个索引，千万别混：

    【ReorderableList.index】
      只有走 ItemList.DoLayoutList() 才会被自动更新。
      虚拟化列表（自己 BeginScrollView + 逐项画）不会更新，
      永远停留在初始值 0 或 -1。

    【sp_SelectedIndex.intValue】
      自己维护的选中索引，通过监听 MouseDown 手动更新。
      虚拟化列表下一切"当前选中项"的读写都必须用它。

    【正确做法】
      - 删除项：用 sp_SelectedIndex.intValue（带越界保护）
      - 插入项：用 sp_SelectedIndex.intValue 作为插入位置
      - 右键菜单：用 for 循环里捕获的局部 index（就是当前项的 index）
      - 详情按钮：用 for 循环里捕获的局部 index
      - 绝对不要用 ItemList.index 做业务判断

    【参考写法】
      private void ItemList_Remove()
      {
          if (sp_ItemLibrary.arraySize <= 0) return;

          int idx = sp_SelectedIndex.intValue;
          if (idx < 0 || idx >= sp_ItemLibrary.arraySize) return;

          sp_ItemLibrary.DeleteArrayElementAtIndex(idx);
          sp_ItemLibrary.serializedObject.ApplyModifiedProperties();

          if (sp_SelectedIndex.intValue >= sp_ItemLibrary.arraySize)
              sp_SelectedIndex.intValue = sp_ItemLibrary.arraySize - 1;
          sp_SelectedIndex.serializedObject.ApplyModifiedProperties();
      }

【G. EditorWindow 专属】
33. EditorWindow 打开时用 Show()，不要用 ShowModal()。
    ShowModal 会阻塞调用方直到窗口关闭，破坏编辑器交互流畅性。
34. 打开 EditorWindow 后设置属性（SetInfo / SetButtonText / SetTitle 等）
    必须在 Show() 之前完成，否则首帧会显示旧状态。
35. 打开 EditorWindow 后若需强制刷新显示，调用 window.Repaint()。

【H. 生命周期】
36. OnDisable 里要 Stop 所有正在运行的 EditorPlayer_*。

37. XGUI.GetBasedIcon("xxx") 的 xxx 必须是项目里真实存在的图标名，
    不确定就用 "icon_field_status"。
38. 契约没覆盖的控件，按以下兜底策略处理：
    - 优先在契约第 2 节里找功能最接近的控件替代
    - 如果实在没有，用 layout_label + layout_button 手搭
    - 生成时加注释：// TODO: 契约未覆盖，需人工确认 XXX

39. 弹窗回调统一用 "按钮文本作为判断依据"：
    if (res == "确定") { ... }
    不要用索引，因为索引会随 PrimaryIndex 变。

40. dialog_listview 的 show_index 参数：
    - true：列表项前显示序号（适合"扫描结果"）
    - false：不显示序号（适合"选择目标"）

41. dialog_submit 返回的 dialog_listdata.state：
    - 是"用户点击的按钮文本"，不是 boolean
    - 判断时写 if (res.state == "保存")

42. layout_progress 的 value 必须 clamp 到 [0, 1]，
    传入超出范围的会绘制错乱：
    float safe = Mathf.Clamp01(myValue);

  - 关键字段：BaseObject / 图标 / 工作副本 / 原始副本 / 布局参数
  - 窗口位置固定用 rect.x + 70 / rect.x + 18 等硬编码偏移对齐


================================================================================
5.2 CustomEditor 黄金样例
================================================================================

CustomEditor 有三种典型形态，生成前先判断属于哪一种：

  5.2.1 简单参数型   —— Banner + 分组容器 + 折叠源脚本
  5.2.2 快捷功能型   —— Banner + 快捷按钮组 + 参数 + 折叠源脚本
  5.2.3 列表管理型   —— Banner + 参数 + 快捷功能 + 虚拟化列表 + 右键菜单

判定规则：
  - 组件只有字段参数，无列表、无工具按钮 → 用 5.2.1
  - 组件有 1~3 个快捷操作按钮，无列表      → 用 5.2.2
  - 组件持有一个 List / 数组需要可视化编辑  → 用 5.2.3

================================================================================
5.2.3 列表管理型 CustomEditor 样例（最重要）
================================================================================

【前置说明】
  - 适用于"组件持有一个 List<Item> 需要可视化编辑"的场景
  - 是 XHud 库编辑器的标准范式
  - 关键：参数区（库名称 + 过滤 + 查找）+ 快捷功能（import/export/clear/create/delete）+ 虚拟化列表
  - 每个列表项支持右键菜单、过滤遮罩、定位标记

【虚拟化列表下的两个索引（必读）】
  - ReorderableList.index
      只有走 ItemList.DoLayoutList() 时才会被自动更新。
      虚拟化列表（自己 BeginScrollView + 逐项画）不会更新它，
      永远停留在初始值 0 或 -1。
  - sp_SelectedIndex.intValue
      自己维护的选中索引，通过监听 MouseDown 手动更新。
      虚拟化列表下一切"当前选中项"的读写都必须用它。
  - 绝对不要用 ItemList.index 做业务判断（增/删/改）。
  - 只渲染循环里的局部变量 i 才是"当前项"的索引。

【虚拟化列表绘制】

    private void DrawItemList()
    {
        scrollview_rect = GUILayoutUtility.GetRect(
            0, sp_visibleItemCount.intValue * sp_itemHeight.floatValue);

        sp_ItemList_Scroller.vector2Value = GUI.BeginScrollView(
            scrollview_rect,
            sp_ItemList_Scroller.vector2Value,
            new Rect(0, 0,
                scrollview_rect.width - 50,
                sp_ItemLibrary.arraySize * sp_itemHeight.floatValue),
            false, true);

        int startIndex = Mathf.FloorToInt(
            sp_ItemList_Scroller.vector2Value.y / sp_itemHeight.floatValue);
        int endIndex = Mathf.CeilToInt(
            (sp_ItemList_Scroller.vector2Value.y + scrollview_rect.height) / sp_itemHeight.floatValue);

        for (int i = startIndex; i < endIndex && i < sp_ItemLibrary.arraySize; i++)
        {
            SerializedProperty prop = sp_ItemLibrary.GetArrayElementAtIndex(i);
            SerializedProperty sp_name = prop.FindPropertyRelative("Name");

            item_rect.Set(0, i * sp_itemHeight.floatValue,
                scrollview_rect.width, sp_itemHeight.floatValue);

            // 选中高亮
            if (sp_name.stringValue.Contains(sp_Highlight.stringValue))
            {
                if (sp_SelectedIndex.intValue == i)
                {
                    item_rect.Set(1, i * sp_itemHeight.floatValue + 12, 5, 5);
                    EditorGUI.DrawRect(item_rect, color_primary);

                    item_rect.Set(0, i * sp_itemHeight.floatValue,
                        scrollview_rect.width + 20, sp_itemHeight.floatValue);
                    EditorGUI.DrawRect(item_rect, SelectedBg);
                }
            }

            item_rect.Set(0, i * sp_itemHeight.floatValue,
                scrollview_rect.width, sp_itemHeight.floatValue);

            ItemList.drawElementCallback.Invoke(item_rect, i, i == ItemList.index, true);

            // 鼠标点击：更新选中
            if (item_rect.Contains(Event.current.mousePosition))
            {
                if (Event.current.type == EventType.MouseDown)
                {
                    if (sp_name.stringValue.Contains(sp_Highlight.stringValue))
                    {
                        sp_SelectedIndex.intValue = i;
                        sp_SelectedIndex.serializedObject.ApplyModifiedProperties();
                        GUI.changed = true;
                    }
                }
            }

            EditorGUI.PropertyField(item_rect, prop, GUIContent.none);
        }

        GUI.EndScrollView();
    }

【列表增删 —— 必须用 sp_SelectedIndex，绝不能用 ItemList.index】

    private void ItemList_Remove()
    {
        // 空列表保护
        if (sp_ItemLibrary.arraySize <= 0)
            return;

        int idx = sp_SelectedIndex.intValue;

        // 索引越界保护
        if (idx < 0 || idx >= sp_ItemLibrary.arraySize)
            return;

        sp_ItemLibrary.DeleteArrayElementAtIndex(idx);
        sp_ItemLibrary.serializedObject.ApplyModifiedProperties();

        // 删除后调整选中索引，避免指向已删除的位置
        if (sp_SelectedIndex.intValue >= sp_ItemLibrary.arraySize)
            sp_SelectedIndex.intValue = sp_ItemLibrary.arraySize - 1;

        sp_SelectedIndex.serializedObject.ApplyModifiedProperties();
    }

    private void ItemList_Add()
    {
        // 无选中 → 追加到末尾；有选中 → 插入到选中项之后
        int insertIndex = sp_SelectedIndex.intValue;

        if (insertIndex < 0 || insertIndex >= sp_ItemLibrary.arraySize)
            insertIndex = sp_ItemLibrary.arraySize;

        sp_ItemLibrary.InsertArrayElementAtIndex(insertIndex);

        SerializedProperty prop = sp_ItemLibrary.GetArrayElementAtIndex(insertIndex);

        // 初始化新项的默认值
        prop.FindPropertyRelative("Name").stringValue = "NewItem";
        // ... 其他默认字段

        prop.serializedObject.ApplyModifiedProperties();

        // 选中新插入的项
        sp_SelectedIndex.intValue = insertIndex;
        sp_SelectedIndex.serializedObject.ApplyModifiedProperties();
    }

5.2.4 带预览型 CustomEditor 样例
================================================================================

【适用场景】
  - 组件有一个 Texture2D / Material 需要在 Inspector 里实时预览
  - 关键：重写 HasPreviewGUI / OnInteractivePreviewGUI

【前置说明】
  - 本样例基于 5.2.1 骨架，额外加了 Inspector 预览区
  - 预览区是 Inspector 底部的独立区域，不是面板内容的一部分

【样例正文（只展示差异部分）】

    // 与 5.2.1 相同，额外加：

    /// 是否有可用的预览界面
    public override bool HasPreviewGUI()
    {
        // 有内容可预览时返回 true（比如有选中的纹理）
        return BaseScript.TargetTexture != null;
    }

    /// 预览面板标题
    public override GUIContent GetPreviewTitle()
    {
        return new GUIContent("Texture Preview");
    }

    /// 可交互预览 GUI（Inspector 底部绘制）
    public override void OnInteractivePreviewGUI(Rect r, GUIStyle background)
    {
        Texture2D tex = BaseScript.TargetTexture;
        if (tex == null) return;

        // 计算等比缩放后居中
        float scaleX = r.width / tex.width;
        float scaleY = r.height / tex.height;
        float scale = Mathf.Min(scaleX, scaleY);

        float w = tex.width * scale;
        float h = tex.height * scale;

        Rect rect_draw = new Rect(
            r.x + (r.width - w) / 2,
            r.y + (r.height - h) / 2,
            w, h);

        XGUI.gui_icon(
            rect: rect_draw,
            icon: tex,
            padding: new RectOffset(0, 0, 0, 0),
            border: new RectOffset(0, 0, 0, 0),
            color: Color.white);
    }

注意观察：
  - HasPreviewGUI 返回 false 时不显示预览区
  - OnInteractivePreviewGUI 里用 gui_icon 绘制（不是 GUILayout）
  - 等比缩放 + 居中，是标准的预览绘制套路

5.2.5 多选批量操作型 CustomEditor 样例
================================================================================

【适用场景】
  - 组件需要支持多选批量编辑（[CanEditMultipleObjects] 已声明）
  - 关键：Targets_Get / Targets_Selected 两个辅助方法 + 批量循环

【前置字段声明】

    private MyComponent BaseScript;
    private MyComponent[] SelectedObjects;

    private SerializedProperty sp_speed;

    private void Targets_Get()
    {
        if (targets.Length > 1)
        {
            SelectedObjects = new MyComponent[targets.Length];
            for (int i = 0; i < targets.Length; i++)
                SelectedObjects[i] = (MyComponent)targets[i];
        }
        else
        {
            SelectedObjects = new MyComponent[targets.Length];
            SelectedObjects[0] = (MyComponent)target;
        }
    }

    private bool Targets_Selected()
    {
        return SelectedObjects != null && SelectedObjects.Length > 1;
    }

【OnEnable 骨架】

    private void OnEnable()
    {
        BaseScript = (MyComponent)target;
        Targets_Get();
        sp_speed = serializedObject.FindProperty("speed");
    }

【批量写入骨架】

    /// 批量修改一个字段
    private void BatchSetSpeed(float newSpeed)
    {
        if (!Targets_Selected())
        {
            // 单选：直接改
            sp_speed.floatValue = newSpeed;
            sp_speed.serializedObject.ApplyModifiedProperties();
            return;
        }

        // 多选：逐个 SerializedObject 包装
        for (int i = 0; i < SelectedObjects.Length; i++)
        {
            SerializedObject so = new SerializedObject(SelectedObjects[i]);
            SerializedProperty sp = so.FindProperty("speed");
            so.Update();
            sp.floatValue = newSpeed;
            so.ApplyModifiedProperties();
        }
    }

【批量读取骨架】

    /// 读取批量模式下当前查看的字段值
    private float GetCurrentSpeed()
    {
        if (!Targets_Selected())
            return BaseScript.speed;

        // 多选时用 sp_speed（serializedObject 指向的 target 是当前 Inspector 主目标）
        return sp_speed.floatValue;
    }

【OnInspectorGUI 骨架】

    public override void OnInspectorGUI()
    {
        serializedObject.Update();

        TextClipping clip = XGUI.TryEllipsisClipping();

        DrawHeader(clip);
        DrawSpeed(clip);

        serializedObject.ApplyModifiedProperties();
    }

    private void DrawSpeed(TextClipping clip)
    {
        fold_param = XGUI.layout_group_start(
            type: XGUIContainerType.Vertical,
            bg_fill: XGUIGroup.缺口纯色边框,
            bg_color: XGUIColor.亮白,
            bg_color_gui: Color.black * 0.3f,
            title: Targets_Selected() ? "参数 - ( 批量模式 )" : "参数",
            title_size: XGUIFontSize.M,
            title_text_color: color_primary,
            title_clipping: clip,
            padding: new RectOffset(10, 10, 15, 15),
            foldout: fold_param);

        if (!fold_param)
        {
            XGUI.ChangedCheck_Start();
            XGUI.layout_property_field(
                title: "速度",
                title_size: XGUIFontSize.M,
                title_hover_color: color_primary,
                title_width: 100,
                prop: sp_speed,
                prop_margin: new RectOffset(0, 0, 5, 0));
            if (XGUI.ChangedCheck_End())
            {
                if (Targets_Selected())
                    BatchSetSpeed(sp_speed.floatValue);
            }
        }

        XGUI.layout_group_end(XGUIContainerType.Vertical);
    }

注意观察：
  - 标题根据 Targets_Selected() 动态切换"批量模式"标识
  - 单选时直接改 sp_xxx；多选时用 BatchSetSpeed 逐个包装
  - 批量写入循环里每个 SerializedObject 都要 Update / Apply
  - Targets_Get 在 OnEnable 里调用一次即可，不要每帧调

--------------------------------------------------------------------------------
8.4 图标调用规则（重要）
--------------------------------------------------------------------------------

不同 API 的路径拼接规则不同，必须严格区分：

  XGUI.GetBasedIcon("xxx")
      → 拼 "Icons/Based/xxx.png"
      → 用于 8.2 节所有图标（含 Anchor/、EaseGraph/ 子目录）

  XGUI.GetIcon("xxx")
      → 拼 "Icons/xxx.png"
      → 用于 8.3 节所有图标（含 Avatars/、Dialogs/、Helpbox/ 子目录）

  XGUI.GetCustomIcon("完整路径")
      → 直接拼 ".png"，不补前缀

  XGUI.GetHelpboxStateIcon(XGUIHelboxState.通知)
      → 内部已封装，等价于 GetIcon("Helpbox/icon_notice")

【禁止事项】
  - 不要给 GetBasedIcon 传带子目录的名字
  - 不要把 r/p 后缀写错（r = 常态，p = 按下）
  - 不要编造未在 8.2 / 8.3 中列出的图标名
  - 不确定图标名时用 "icon_field_status" 或 HelpboxState

【播放 / 停止 / 回退】
  icon_play_r / icon_play_p          （播放）
  icon_stop_r / icon_stop_p          （停止）
  icon_rewind_r / icon_rewind_p      （回退）

  icon_path_r / icon_path_p          （路径）
  icon_locate                        （定位）
  icon_mark_arrow_left               （左箭头）
  icon_mark_arrow_right              （右箭头）
  icon_mark_arrow_up                 （上箭头）
  icon_mark_arrow_down               （下箭头）

【增删改】
  icon_add_r / icon_add_p            （添加）
  icon_clear_r / icon_clear_p        （清空）
  icon_recycle_r / icon_recycle_p    （回收 / 重置）
  icon_strike                        （删除线 / 失效）

【对话框】
  icon_dialog_r / icon_dialog_p      （弹窗）
  icon_warning                       （警告）
  icon_warning_solid                 （警告实心）

【状态 / 字段】
  icon_field_status                  （字段状态点）
  icon_arrow                         （下拉箭头）

  Dialogs/icon_confirm               （确认）
  Dialogs/icon_error                 （错误）
  Dialogs/icon_help                  （帮助）
  Dialogs/icon_modified              （修改）
  Dialogs/icon_notice                （通知）
  Dialogs/icon_warning               （警告）
  Helpbox/icon_error                 （帮助框 - 错误）
  Helpbox/icon_notice                （帮助框 - 通知）
  Helpbox/icon_warning               （帮助框 - 警告）

【按用途选图】
  需要"添加" → 用 icon_add_r / icon_add_p
  需要"删除" → 用 icon_strike 或 icon_clear_r
  需要"重置" → 用 icon_recycle_r
  需要"定位" → 用 icon_locate
  需要"下拉箭头" → 用 icon_arrow
  需要"字段状态" → 用 icon_field_status
  需要"帮助框" → 用 GetHelpboxStateIcon 而不是 GetIcon
